PS5

  1. Einstellungen → Netzwerk → Einstellungen
  2. Internetverbindung einrichten → deine Verbindung → Erweiterte Einstellungen
  3. DNS-Einstellungen: Manuell, dann beide Adressen eintragen → OK

Xbox

  1. Einstellungen → Allgemein → Netzwerkeinstellungen
  2. Erweiterte Einstellungen → DNS-Einstellungen → Manuell
  3. Beide Adressen eintragen, fertig
